# SteamOSXX v0.7.1: sleep (opt-in), FEX tools install themselves

## What's new

- **Sleep (opt-in).** Both handhelds now sleep and wake with the kernel's s2idle, no firmware support needed. Tested with Steam running
  and with a game in front: the panel, USB, Steam, the controller and the game come back, the Wi-Fi of the RG40XX-H reconnects about 8 s after
  waking. It is off by default because waking by the **power button** has not been confirmed on every unit yet, and a sleeping
  handheld that does not wake looks dead. To try it: create an empty file named `sleep` on the card's `STEAMBOOT` partition (or run
  `sxx-sleep on` over SSH or adb); a short press of the power button then sleeps, a long press powers off, and Steam's Power > Sleep works.
  `sxx-sleep test` sleeps through the real path with an RTC alarm as a safety net and tells you what woke it: `power-button` means it
  works. Please run it and press the power button while it sleeps, then tell us what it printed.
- **Valve's FEX tool and the x86 runtime install themselves.** With a Linux x86 game installed, the first start asks Steam for both
  (FEX and Steam Linux Runtime 4.0) and presses Install on Steam's dialog, again every two minutes until they are there; Steam must be online.
  Before, this was a manual step.
- **Games with windows bigger than the screen now fit.** Old Linux games open 800x600 or 1280x720 windows (Eets, Hotline Miami) that were
  cut off on the 640x480 panel; the focus daemon now scales the whole screen to such a window while it has the focus, letterboxed and done by
  the GPU, and puts it back when you return to Steam.
- **RG28XX: the network comes up 25 s sooner** (the Wi-Fi helper no longer waits for a chip that is not there).
- Under the hood: CI now boots the latest published release in the virtual device and updates it in place to every build; measured
  Wi-Fi and SD speeds and the Mali's Vulkan features are in `docs/roadmap.md` and `docs/research/panvk-vulkan-dxvk.md`.

## Updating

Settings > System > Check For Updates, Apply, Restart (RG28XX and RG40XX-H both).

## Known issues

- Sleep is off until you turn it on (above). Sleeps of up to a minute woke reliably on both handhelds; a 30-minute sleep on one RG40XX-H did
  not come back by itself (cause not found yet), so do not rely on it for long sleeps. Battery use while asleep is not measured yet.
- Booting the RG28XX from slot 1 with no muOS has not been tried.
