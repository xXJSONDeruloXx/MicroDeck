# SteamOSXX v0.7.0: RG28XX

The Anbernic RG28XX now runs SteamOSXX too, and a launch-screen glitch is gone.

## What's new

- **RG28XX support.** The release has one image per handheld, `steamos-rg40xx.img.xz` and `steamos-rg28xx.img.xz`, built from the same
  Debian, Steam, kernel and updater. They differ only in U-Boot (the unit's own RAM timings, read from its stock boot0: LPDDR4 at 672 MHz,
  three delay values differ from the RG40XX-H) and the device tree. Checked on a real RG28XX: boots, the 480x640 portrait panel (rotated
  to 640x480 landscape to match the kernel's idea of the mounting), the built-in pad with rumble, backlight, audio, battery, Steam in Big
  Picture, Geometry Wars through Proton, Hotline Miami and Eets through FEX, and the in-game Steam menu. An in-place update from GitHub
  to this release was run on both handhelds. In-place updates download the image for the handheld they run on.
- **The RG28XX has no Wi-Fi.** It appears as a USB network adapter when plugged into a PC (no driver on Windows 11, macOS or Linux) and
  answers at 169.254.58.58 even with no setup (SSH, adb). The first start downloads Steam, so share the PC's connection with it: on Windows run
  `tools/win-share-usb.ps1` from an elevated PowerShell (Internet Connection Sharing); the handheld then gets internet by DHCP.
  The first-start screen says so instead of asking for a Wi-Fi file. Everything else (Steam login with the QR code, games) is as on
  the RG40XX-H.
- **No gray "cast" square over the controller diagram** on a game's launch screen (and any other video). It was Chromium's own cast
  button, drawn on every video; a small service (`sxx-ui-fixes`) now switches it off as Steam creates each one.
- **Hotline Miami starts without its Qt launcher window** (a Linux game whose Steam entry is a launcher that needs a pointer): the game binary
  runs directly. Checked end to end on both handhelds.
- Under the hood: `DEVICE=rg28xx tools/build-image.sh`, a CI matrix for both images, smoke test that accepts USB Ethernet, `tools/dev.sh` can
  pick one of two handhelds online at once.

## Updating

From v0.6.0 on an RG40XX-H: Settings > System > Check For Updates, Apply, Restart. An RG28XX needs a fresh flash of
`steamos-rg28xx.img.xz` (see the README, Install); after that it updates itself.

## Known issues

- The RG28XX values come from one unit; if yours fails to boot (black screen), a different RAM revision is the likely reason.
- RG28XX: no Wi-Fi hardware, so every download goes through the PC's shared connection; no sleep and wake yet (as on the RG40XX-H).
- Slow, as before; windows bigger than the 640x480 panel (Eets, 800x600) are clipped.
- Steam's own cloud sync can stall launches when several devices share an account; Steam's offline mode avoids it.
