# SteamOSXX v0.6.0: Linux x86 games

Games that only have a Linux build now run, through Valve's FEX emulator, straight from Steam.

## What's new

- **Native x86 Linux games under FEX.** A Steam compatibility tool, "Linux x86 (FEX)" (`sxx-fex`), runs a game's 32-bit or 64-bit
  x86 Linux build on the Cortex-A53, with OpenGL going to the Mali through FEX's GL thunk. It uses Steam Linux Runtime 4.0's x86
  libraries as the guest system and fills gaps (libvorbisfile, OpenAL 1.16, libGLU) from the old Steam Runtime. Installed games that
  have only a Linux build are mapped to it automatically before Steam starts. First tests: Hotline Miami (32-bit; window up 22 s
  after launch) and Eets (64-bit, in front in about 30 s). Steam asks once to install two helper tools: Valve's "FEX" and "Steam
  Linux Runtime 4.0". Expect slow first starts while FEX translates code.
- **Games with no `_NET_WM_PID` come to the front.** SDL 1.2 games never tag their window, so Steam's UI stayed on top of a running
  game (sound, no picture). The focus daemon now asks the X server who owns the window.
- **Memory:** `vm.overcommit_memory=1`. FEX reserves several GB of address space per process; the default heuristic refused it and
  every fork inside an emulated game failed.
- **Recovery:** put a file `recovery.txt` containing `sxx=previous` on the boot partition (from any PC) and the next boot reinstalls
  the previous release, if one is kept. The updater also refuses to start below 40 % battery without the charger.
- **Rumble:** a kernel patch for a deadlock in the gamepad driver's rumble path (the force-feedback timer calls a function that
  takes a sleeping lock). Found by the Handtop project on the RG35XX-H, same driver. Not yet verified on this handheld.
- **A 16 % smaller image** (about 300 MB instead of 360 MB): translations, man pages and docs are gone (licence files stay), so
  updates download and unpack faster.
- Under the hood: a virtual device (QEMU) with the real initramfs and image, unit tests and a boot test in CI, an agent handbook
  (`docs/agents.md`), and fixes found by the virtual device: the data partition is found on any disk name, and SSH keys are
  imported again when the installed key file is empty.

## Updating

Settings > System > Check For Updates, Apply, Restart (from v0.4.0). A new image is only needed for U-Boot changes.

## Known issues

- Slow, as before. Games with a launcher (Hotline Miami) need the launcher's Start button pressed with a pointer; windows bigger
  than the 640x480 panel (Eets, 800x600) are clipped.
- No sleep and wake yet (the virtual Deck controller blocks suspend and no wake source works; see docs/roadmap.md).
- Steam's own cloud sync can stall launches when several devices share an account; Steam's offline mode avoids it.
