# SteamOSXX v0.7.2: sleep wakes after any length of time

## What's new

- **Sleep no longer breaks the network after a long nap.** Found with the opt-in sleep of v0.7.1: after a sleep longer than three minutes
  systemd killed logind, the journal and the time service at the moment of waking (their watchdogs had "expired" while the handheld slept),
  and NetworkManager then stayed asleep, so the USB network of the RG28XX and the Wi-Fi of the RG40XX-H never came back. Those watchdogs are
  switched off. The RG28XX woke from 3, 10 and 30 minute sleeps (the network problem showed in all of them) and, with the fix, from a
  4-minute sleep with the network back 16 s later and no service killed. Still opt-in: create an empty file named `sleep` on the card's
  `STEAMBOOT` partition (or run `sxx-sleep on`), then `sxx-sleep test` and press the power button while it sleeps. If it prints `power-button`,
  waking by the button works on your unit; please tell us.
- Everything from v0.7.1: games with windows bigger than the screen (Eets, Hotline Miami) now fit it, Valve's FEX tool and the x86 runtime
  install themselves, the RG28XX's network comes up 25 s sooner.

## Updating

Settings > System > Check For Updates, Apply, Restart.

## Known issues

- Sleep is off until you turn it on; waking by the power button has not been confirmed yet, and battery use while asleep is not measured.
- Booting the RG28XX from slot 1 with no muOS has not been tried.
