# MicroDeck v0.9.0: desktop mode

## What's new

- **Desktop mode.** In Steam, open **Power > Switch to Desktop** (confirm) for a small controller-driven desktop with a browser (Firefox ESR),
  documents (AbiWord), spreadsheets (Gnumeric), a text editor, a file manager and a terminal. It is meant for the things a game console does
  not do: reading a page, editing a document. The desktop starts in about 20 seconds and leaves Steam closed while you use it, which frees
  about 300 MB for the apps; a click on the panel's **Steam** button, **Return to gaming mode** in the menu, or holding **Start** for two
  seconds brings Steam back.
- **The pad is the mouse and keyboard.** D-pad (and sticks, where the handheld has them): pointer, speeding up while held; **A** left click
  (hold to drag), **B** right click, **L2** + d-pad scrolls, **Start** opens the menu, **Select** switches to keys mode (d-pad sends
  arrow keys, A Enter, B Esc) for menus and lists, **X** opens an on-screen keyboard you move around with the d-pad (A types, L1 is Shift).
  The panel shows the current mode (MOUSE, KEYS, SCROLL, KEYBOARD), the battery and the clock.
- Firefox is set up for 1 GB of RAM (one shared web process, small caches). One tab at a time is comfortable; on a long Wikipedia page
  with two tabs about 250 MB stays free.
- The apps are in the image (430 MB installed, 275 MB of it Firefox), so the download is bigger than before.

## Updating

Settings > System > Check For Updates, Apply, Restart. This is the first release you reach from v0.8.0 that way.

## Known issues

- Desktop mode was exercised on an RG28XX with a virtual pad: the real buttons' layout, and the RG40XX-H, have not been tried. Pointer
  speed will need tuning on real hands.
- GTK apps look large on the RG28XX's 480x640 portrait panel.
- Sleep is still opt-in; waking by the power button is not confirmed. Booting the RG28XX straight from slot 1 has not been tried.
