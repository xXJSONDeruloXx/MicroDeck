# MicroDeck v0.9.1: a faster Steam UI, games that scale, sleep on

## What's new

- **The Steam UI is far cheaper to draw.** Valve's UI blurs its backgrounds and panels, which a software renderer on four A53 cores pays for in
  every frame: the library home page sat at about 190 % CPU with nobody touching it and drew about 5 frames per second. With the blur off
  it idles near 10 % and draws 56 frames per second, scrolling the library uses a third less CPU, and the handheld runs cooler. Panels are
  opaque and backgrounds sharp instead of blurred. To get Valve's look back, set `UI_BLUR=1` in `/etc/steam-session.conf`.
- **Games are scaled to the panel without flicker.** A new scaler (`mdeck-scale`) draws the focused game window scaled to the screen with
  the GPU, as gamescope does, with Steam's own menu on top. The screen is never resized any more, so the game never sees its display change:
  that change made Wine games shrink their own windows and the panel flicker. Sonic Mania in its default windowed mode now fills the
  panel (it was a small window with a title bar), old games with big windows (Eets) fit, and the scaler uses no memory when nothing needs
  scaling. If you set a scaling filter or mode in Steam's quick access menu (nearest, integer, fill, stretch) it is honoured.
- **Sleep is on by default.** A short press of the power button sleeps, a long press powers off, and the next press wakes. Waking from the
  power button works on the RG40XX-H; 4-minute and 30-minute sleeps wake with the network back. To switch sleep off, create an empty file named
  `nosleep` on the card's `MICRODECK` partition or run `mdeck-sleep off`.
- Desktop mode: the terminal uses a readable font, and the panel shows no empty battery label on a unit without a battery.
- Cards from before the rename: Steam's web helper wrapper is found again under the new state folder, so an unclean shutdown no longer
  makes Steam re-extract itself.

## Updating

Settings > System > Check For Updates, Apply, Restart.

## Known issues

- Mouse and touch input is not mapped through the scaling, so a game that needs the mouse while its window is scaled sees shifted positions
  (pad-driven games are not affected).
- Sonic Mania runs at a few frames per second: it is an x86 Windows game translated on the CPU (about two cores).
- Booting the RG28XX straight from slot 1 has not been tried; the RG28XX's power-button wake is not confirmed.
